# Installing the library

The library is built as **ESM** and ships TypeScript type declarations. Consumers must install **React 18+** themselves.

## Install from a monorepo / local path

Point your application `package.json` to this package (adjust based on your package manager strategy):

```json
{
  "dependencies": {
    "@syncai/design-system": "workspace:*"
  }
}
```

## Import in your application

```tsx
import { Button } from '@syncai/design-system';
import '@syncai/design-system/styles.css';
```

The style file brings in the design **tokens** and the component styles. If you already have a global theme, you can import only the components and override the CSS variables.

## Build the library

```bash
npm run build
```

Outputs into `dist/`: `index.js`, `index.d.ts`, `styles.css`.
