# Installing the library

The library is built as ESM and ships TypeScript type declarations.

## Install from a monorepo

```json
{
  "dependencies": {
    "@syncai/design-system": "workspace:*"
  }
}
```

## Import in your application

```tsx
import { Button } from '@syncai/design-system';
```

## Build the library

```bash
npm run build
```
