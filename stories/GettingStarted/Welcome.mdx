# Welcome

**SyncAI Design System** is a documentation site for the team's shared UI components and design vocabulary. Its goal is similar to the [Strapi Design System](https://design-system.strapi.io/?path=/docs/getting-started-welcome--docs): develop, showcase, and test components in an isolated environment, and explain how to use them through documentation pages.

## What's in this site?

| Section | Description |
|------|------|
| **Getting Started** | Welcome page, installation, and onboarding |
| **Components** | APIs for each component, interactive examples, and accessibility checks (A11y addon) |

## Local development

```bash
npm install
npm run dev
```

Open Storybook in your browser (default `http://localhost:6006`). For static output:

```bash
npm run build-storybook
```

The output directory is `storybook-static/`, which you can deploy to any static hosting.
