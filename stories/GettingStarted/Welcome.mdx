# Welcome

**SyncAI Design System** 是團隊共用的 UI 元件與設計語彙文件站。目標與 [Strapi Design System](https://design-system.strapi.io/?path=/docs/getting-started-welcome--docs) 類似：在獨立環境中開發、展示與測試元件，並以文件頁說明使用方式。

## 這個網站裡有什麼？

| 區塊 | 說明 |
|------|------|
| **Getting Started** | 歡迎頁、安裝與導入方式 |
| **Components** | 各元件的 API、互動範例與無障礙檢查（A11y addon） |

## 本機開發

```bash
npm install
npm run dev
```

瀏覽器開啟 Storybook（預設 `http://localhost:6006`）。靜態站輸出：

```bash
npm run build-storybook
```

產出目錄為 `storybook-static/`，可部署到任意靜態託管。
